# AWS SAA-C03 模擬考

單一 HTML 檔案的 AWS Certified Solutions Architect – Associate (SAA-C03) 模擬考題庫，純前端、無需後端。

## 線上使用

透過 GitHub Pages 部署：`https://<你的 GitHub 帳號>.github.io/Project-saa_mockexam/`

## 本機使用

直接用瀏覽器開啟 `index.html` 即可。

## 自訂網域

申請好網域後，可在 repo 的 **Settings → Pages → Custom domain** 填入網域，GitHub 會自動建立 CNAME 檔案；接著到你的網域註冊商設定 DNS（CNAME 指向 `<你的帳號>.github.io`，或 A 記錄指向 GitHub Pages IP）。
